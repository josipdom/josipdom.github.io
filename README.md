# josipdom.github.io

Personal portfolio. Plain HTML + CSS, no build step, no JavaScript, no trackers.

- `index.html`: all content
- `style.css`: styles and colour palette (`:root` variables)
- `favicon.svg`: icon

## Add a project

Copy one `<article class="project">` block inside `#projects`, put it at the top and change the text.

## Preview locally

Open `index.html` in a browser, or run `python -m http.server` in this folder and open http://localhost:8000.
